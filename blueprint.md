# Project Blueprint

## Overview

This project is a network speed test application built with Next.js. It allows users to measure their ping, download speed, and upload speed.

## Implemented Features

*   **Ping Test:** Measures the latency to the server.
*   **Download Speed Test:** Measures the download speed from the server.
*   **Upload Speed Test:** Measures the upload speed to the server.
*   **User Interface:** A simple and intuitive interface to display the results.
*   **Geo-information:** Displays the user's IP address and location.

## Design and Style

*   **Layout:** A centered layout with a title, results section, and a start button.
*   **Styling:** The application uses a custom stylesheet for a clean and modern look.
